# LAGI – Umweltmanagement ISO 14001

Interaktives, eigenständiges LAGI-Modul für **Umweltmanagement ISO 14001**.

## Funktionen

- Übersicht mit Handlungsbedarf und Fälligkeiten
- Fachlich gegliederte Register
- Datensätze anlegen, bearbeiten, löschen und durchsuchen
- CSV- und JSON-Export
- Browserlokale Speicherung ohne externe Skripte oder Backend
- Offizielle Quellen direkt im Informationsdialog

## Verwendung

`index.html` direkt im Browser öffnen oder als statische Website bereitstellen. Alle Beispielangaben sind fiktiv. Die Anwendung unterstützt die Dokumentation und ersetzt keine fachliche Einzelfallprüfung.
